# T0.1 — Repository and environment

Status: complete. Supplementary Note S12.

The independent analysis project is `scRNAseq/VirtualTissue-SC`. Original and
derived data are in sibling `scRNAseq/data/SPECIAL/`, outside the Git repository.
The validated VirtualTissue-Xenium runtime was not modified.

The scientific Python environment is pinned in `requirements.lock.txt` and
`environment.yml`, with the interpreter in `.python-version`. The R environment
is pinned in `renv.lock`; `sessionInfo.txt` records the actual loaded runtime.
CmdStanPy is available as an interface, but a Stan compiler/model is not installed
or selected. The inference backend remains a T3.1 decision.

Validation:

- Installed into an empty Python environment, then restored all pinned packages
  into a second empty environment. Package versions match exactly.
- Restored `renv.lock` into a separate R library and loaded the required packages.
- Scientific imports, a synthetic matrix exponential, and a Parquet round trip
  passed. The actual Seurat object is readable with the installed packages.
- Integrity tests passed in both Python environments, including rejection of
  truncated downloads, same-size corruption and modified freeze inputs.

Evidence: `reports/evidence/python-reproducibility.json`, `python-smoke.json`,
`pytest.xml`, `pytest-reproduced.xml`, `r-reproduce-install.log` and
`sessionInfo.txt`; hashes in `reports/EVIDENCE_SHA256.json`.

R binaries for some dependencies report having been built under the next R
patch release. Imports and the actual export/count round trips passed; this
warning is preserved in the logs. The environment is validated on this macOS
ARM host, not on an untested Linux/Colab host.
