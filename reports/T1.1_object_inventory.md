# T1.1 — Object inventory and neutral export

Status: complete. Supplementary Note S2, Supplementary Table S2.

The deposited immune object is a Seurat object with stored version 3.1.5.
It contains 25,178 cells and an RNA assay with 22,897 features, plus an SCT
assay and author PCA, Harmony and UMAP embeddings. The RNA raw-count matrix was
exported by sample to MatrixMarket with `obs.parquet`, `var.tsv` and archival
embeddings. There was no cell filtering or reannotation.

Every exported sparse matrix exactly matches the original element values,
cell and gene totals, matrix dimensions and cell order after read-back. Metadata
also pass a read-back comparison. All cells were exported exactly once.
Per-file SHA-256 hashes and checks are in
`reports/evidence/immune-export-validation.json`.

The deposited cell count differs from the published 25,401. The reason for this
cell-level difference is not established; it is not explained merely by the
absent biopsy. The clinical join identifies the absent sample separately in T1.2.
The author vocabulary contains `Doublets` and `Cycling_cells`; no assumption is
made that these labels are eligible primary CD8 states. The four published
CD8-state labels define the provisional lineage count only; T2.1 is still required
for a biological QC audit if a revised study proceeds.

The metadata dictionary is `tables/S2_metadata_dictionary.tsv`. Counts-derived
QC fields are explicitly distinguished from deposited metadata. The original
object lacks per-cell UMI/gene/mitochondrial fields, so these were recomputed
from RNA counts. The mitochondrial rule is the human `MT-` symbol prefix.

Author embeddings are preserved for provenance only. They must not be used as
training/test representations: they were fitted by the authors across their
cohort. Future representations must be fitted within each training fold.
State/outcome metadata are archived, but no state compositions were generated.
