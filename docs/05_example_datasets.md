Sources and licences checked on **2026-10-27**. Public availability is not itself
a licence; the real examples below have an explicit source declaration.

| SPECIAL and the integrated Lin atlas | Source-specific restrictions, including SPECIAL CC BY-NC-SA | Historical research audit; not needed or read by the software demonstration |

The synthetic example is a minimal generated count matrix with known initial
labels. It supports deterministic tests and analytical model checks; it does
not emulate every feature of real scRNA-seq noise or validate a disease model.

PBMC3k is a healthy-blood snapshot. Its original matrix contains 2,700 cells and
32,738 feature IDs. The pinned archive is 7,621,991 bytes with SHA-256
`847d6ebd9a1ec9a768f2be7e40ca42cbfe75ebeb6d76a4c24167041699dc28b5`.
It is fetched directly from 10x, verified before extraction, and stored locally.
`examples/datasets.json` records the URL, licence and attribution. The downloader
also writes `SOURCE.json` next to the original archive.

Suggested attribution: **10x Genomics, “3k PBMCs from a Healthy Donor”, Cell
Ranger 1.1.0, 2016, CC BY 4.0. Changes: selected a marker-positive subset,
assigned illustrative expression labels and initialized a software simulation
under declared rates.** Include the dataset and
[licence](https://creativecommons.org/licenses/by/4.0/) links with shared derivatives.

## Fixed PBMC demonstration recipe

1. Select cells with `CD3D + CD3E > 0` and `CD8A + CD8B > 0` in raw counts.
2. Calculate mean counts across `CCR7, IL7R, TCF7` (Resting-like), `GZMK`
   (GZMK-like), and `NKG7, GNLY, PRF1, GZMB` (Cytotoxic-like).
3. Assign the largest score. Ties use the listed order, including all-zero ties.
4. Use the fixed model's declared rates; no rate is learned from those scores.

The verified file yields 427 selected cells before optional subsampling.
This recipe is an intentionally transparent **test fixture**. Dropout, marker
overlap and doublets can cause classification errors. These scores are not
AUCell, protein activity or validated functional states. The labels do not
establish trajectories, exhaustion, antigen recognition or treatment response.
Use reviewed annotations for your own scientific work.

The default example stores no downloaded raw expression in Git. If you share
a derived PBMC input bundle or results, retain attribution and the source licence.
User-provided datasets retain their own terms; `--source-license` records the
user's declaration and does not grant permissions.
