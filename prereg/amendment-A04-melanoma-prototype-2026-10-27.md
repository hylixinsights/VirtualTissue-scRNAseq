# A04 — Correct software prototype to dissociated melanoma

Date: 2026-10-27. Status: user-directed software scope correction, implemented
locally; no clinical research gate is passed by this amendment.

The user explicitly rejected PBMC and an arbitrary cell-state grid and reaffirmed
the objective: simulate melanoma from cells dissociated for 10x, with interacting
agents and a visual/inspection workflow comparable to VirtualTissue-Xenium.
This supersedes A03's choice of a PBMC/nonspatial demonstration as the primary
software workflow. A03 remains an historical record.

Use the official CC BY 4.0 10x dissociated melanoma matrix, a synthetic melanoma
fixture for offline tests, and a documented own-biopsy pipeline. Implement a
separate, explicitly uncalibrated 2D agent engine with assumed geometry, local
legal actions, transparent rule decisions, contact-gated effects, recorded events
and a tissue viewer. All source/program/geometry/rate assumptions remain visible.
No Jev/API spending, patient prediction or measured spatial reconstruction is implied.

The original SPECIAL/Lin plan, frozen config, candidate counts, licensing and
feasibility gates are unchanged. This software prototype does not fit those data,
consume a lockbox or imply that their research gates have passed. A future
clinical or biological validation claim still requires its planned evidence.
