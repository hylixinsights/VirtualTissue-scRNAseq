# A03 — Independent software-test prototype

On 2026-10-27 the user clarified that the immediate objective is a usable
pipeline for group members to run their own data and test simulation behavior,
using permitted public/synthetic examples and documentation comparable to
VirtualTissue-Xenium.

This authorizes building and testing an **uncalibrated non-spatial software
prototype** despite the clinical study's failed feasibility prerequisite. It
does not authorize relaxing the frozen clinical thresholds, fitting a SPECIAL
model, assigning/opening a lockbox, asserting patient prediction, or proceeding
to spatial/Jev experiments.

Deliverables: explicit H5AD/Matrix Market input contract; synthetic and CC BY
PBMC example; checksum bundle; declared-rate stochastic state/division/death/
influx engine; exact expectation comparator; no-events control; event journal;
offline explorer; local/Colab notebooks; README; meaningful numerical and data
integrity tests. The complete existing research record and original freeze are
preserved. Synthetic fixtures and original software use MIT; third-party data
retain their own licences.

Acceptance for software testing is correct implementation, reproducibility,
usable inputs/results and clear assumptions. It is not a biological validation
gate. The future predictive research pipeline still needs a feasible cohort,
state calibration, access guards, estimation/recovery and held-out evaluation.
